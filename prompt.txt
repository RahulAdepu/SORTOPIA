## 1. GAME VISION

Create a visually beautiful, satisfying, addictive color-sorting puzzle game.

The central gameplay is simple:

Players receive several transparent containers filled with layers of different colored liquids. Their objective is to sort the liquids so that every container contains only one color.

The game should be easy to understand within seconds but increasingly challenging as players progress.

Build an original game experience inspired by successful casual puzzle games. Do not copy any existing game's branding, artwork, layouts, animations, or proprietary assets.

## 2. CORE GAMEPLAY

Each level contains:
- Multiple transparent glass containers.
- Different colored liquid layers.
- One or more empty containers.
- A defined move limit or optional challenge.
- A target arrangement.
- A level completion condition.

Rules:
1. Select a container.
2. Select another container as the destination.
3. Pour liquid only when the move is valid.
4. Pour only into an empty container or a container with a matching top color.
5. Never exceed the destination's capacity.
6. Complete the sorting objective.
7. Receive a score and rewards.
8. Unlock the next level.

Implement accurate game-state validation.

Support undo, restart, and hints.

Ensure every generated puzzle is solvable.

## 3. GAME MODES

Create these game modes:

### Classic Mode
Progress through increasingly challenging color-sorting puzzles.

### Time Challenge
Complete puzzles before the timer expires.

### Limited Moves
Solve the puzzle using a restricted number of moves.

### Daily Challenge
Offer a special daily puzzle using a deterministic date-based seed. The same daily challenge should produce the same puzzle for all players where practical.

### Zen Mode
Relaxed sorting without timers or move restrictions.

Build the architecture so additional modes can be introduced later.
